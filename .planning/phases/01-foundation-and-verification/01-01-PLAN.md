## Technical direction

The `pnpm create next-app@latest . --typescript --tailwind --eslint --app --no-src-dir --import-alias "@/*"` command must be run with `.` (current directory) as the target because the repo and `.planning` files already live in `webbuild`. The create command will write `package.json`, `tsconfig.json`, `.gitignore`, and the initial `app/` scaffold without clobbering `.git` or `.planning`.

After scaffolding, the Phase 1 deps are added with `pnpm add three@0.183.2 @react-three/fiber@9.6.0 @react-three/drei@10.7.7 zustand@5.0.12`. The `three` entry in `package.json` must be the exact string `"0.183.2"` with no range prefix — edit `package.json` after `pnpm add` if pnpm writes `^0.183.2`. The `next.config.ts` webpack alias block prevents `three/webgpu` from being evaluated server-side (belt-and-suspenders alongside `dynamic({ ssr: false })` that Plan 02 adds).

Stub routes only need to return a minimal JSX fragment; they are placeholders that satisfy the three-route requirement for Phase 1 SC#1. The `/text/[slug]/page.tsx` dynamic segment must exist so that `/text/hello` resolves — Next.js App Router will match `hello` as the `slug` param without any additional config. The `public/poster.jpg` placeholder can be a single-line data URI written as a real JPEG file via a Node one-liner or equivalent — Phase 1 only requires the file to serve, not to look good.

Vercel CI is a human action because the CLI requires interactive OAuth. The task below spells out the exact steps so the developer can complete it in under 5 minutes.
