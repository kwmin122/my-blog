## Objective

Wire the persistent R3F canvas into the Next.js layout and implement the full three-tier renderer fallback chain: WebGPU -> WebGL2 -> static poster. Add the `performance.mark()` measurement scaffold so that every local or production page load prints `[perf] /world first-frame: Xms` and `[perf] /text LCP: Xms` to the browser console. After this plan, a developer can open any of the three routes in Chrome Canary (WebGPU), Chrome stable (WebGL2), or a canvas-blocked environment (poster) and observe the correct renderer selection and perf output — the v0.1 skeleton is functionally complete.

## Capabilities

- CORE-01: Single WorldCanvas in `app/layout.tsx` via `dynamic({ ssr: false })`, never remounts on route change.
- CORE-05: WebGPU -> WebGL2 auto-fallback via `forceWebGL: mode === 'webgl2'` in the `gl` async factory.
- CORE-06: Static poster image + `/text/` banner link when both WebGPU and WebGL2 are unavailable.

## Technical direction

`WorldCanvas.tsx` must be a `'use client'` module. It is loaded in `app/layout.tsx` via `dynamic(() => import('@/components/world/WorldCanvas'), { ssr: false })`. The `ssr: false` guard prevents `three/webgpu` from being evaluated during server rendering even if a future refactor accidentally removes the `'use client'` directive. The `next.config.ts` webpack alias (`'three/webgpu': false` on server) is a third layer of protection.

The `detectMode()` function runs inside a `useEffect` (client-only), sets `RendererMode` state, and gates rendering. While state is `null` (the hydration window), the component returns `null` to avoid a server/client HTML mismatch. This is the standard pattern for browser-only detection code in Next.js App Router.

The `gl` prop on `<Canvas>` accepts an async factory that returns a renderer instance. The factory creates `new THREE.WebGPURenderer({ ...props, forceWebGL: mode === 'webgl2' })`, then calls `await renderer.init()`. The `await` is critical — omitting it causes a blank canvas with no error. On failure, the factory catches the error, calls `setMode('poster')`, and returns `null`, which causes R3F to render the `fallback` prop (`<StaticPosterFallback />`). The `data-canvas-id` attribute lives on a wrapper `<div>` around `<Canvas>` because R3F does not forward arbitrary HTML attributes to the underlying `<canvas>` element.

The `StaticPosterFallback` component renders `public/poster.jpg` as a fixed full-viewport background with a `/text/` link in the lower center. For Phase 1 the image is the 1x1 black pixel placeholder from Plan 01 — the design is intentionally deferred to Phase 5.

`WorldScene.tsx` is an empty R3F scene that uses `useFrame` with a `useRef` guard to call `markWorldFirstFrame()` exactly once on the first rendered frame. The `lib/perf.ts` `observeTextLCP()` function is called from the `/text/[slug]` route via a small client component wrapper that registers the `PerformanceObserver` in a `useEffect`.

export function markWorldFirstFrame() {
  if (typeof performance === 'undefined') return
  performance.mark('world-first-frame')
  const nav = performance.getEntriesByType('navigation')[0] as PerformanceNavigationTiming
  const delta = performance.now() - (nav?.startTime ?? 0)
  console.log(`[perf] /world first-frame: ${delta.toFixed(1)}ms`)
}

export function observeTextLCP() {
  if (typeof PerformanceObserver === 'undefined') return
  const po = new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
      console.log(`[perf] /text LCP: ${entry.startTime.toFixed(1)}ms`)
    }
  })
  po.observe({ type: 'largest-contentful-paint', buffered: true })
}

```tsx
'use client'

import { useEffect, useState } from 'react'
import { Canvas } from '@react-three/fiber'
import { extend } from '@react-three/fiber'
import * as THREE from 'three/webgpu'
import WorldScene from './WorldScene'

// Register three/webgpu classes with R3F's JSX catalog
extend(THREE as any)

type RendererMode = 'webgpu' | 'webgl2' | 'poster'

function detectMode(): RendererMode {
  if (typeof navigator === 'undefined') return 'poster'
  // Check WebGL2 availability first — required for both WebGL2 and WebGPU paths
  const testCanvas = document.createElement('canvas')
  const gl2 = testCanvas.getContext('webgl2')
  if (!gl2) return 'poster'
  // navigator.gpu presence indicates WebGPU is likely available
  // Actual init failure is caught in glFactory and triggers poster fallback
  if (navigator.gpu) return 'webgpu'
  return 'webgl2'
}

function StaticPosterFallback() {
  return (
    <div style={{ position: 'fixed', inset: 0, zIndex: 0, background: '#0a0a0a' }}>
      <img
        src="/poster.jpg"
        alt="3D World — upgrade your browser to explore"
        style={{ width: '100%', height: '100%', objectFit: 'cover' }}
      />
      <div
        style={{
          position: 'absolute',
          bottom: 24,
          left: '50%',
          transform: 'translateX(-50%)',
          color: 'white',
          whiteSpace: 'nowrap',
        }}
      >
        <a href="/text" style={{ color: 'inherit', textDecoration: 'underline' }}>
          텍스트로 읽기 →
        </a>
      </div>
    </div>
  )
}

export default function WorldCanvas() {
  const [mode, setMode] = useState<RendererMode | null>(null)

  useEffect(() => {
    setMode(detectMode())
  }, [])

  // null during SSR hydration window — renders nothing until client detects mode
  if (mode === null) return null
  if (mode === 'poster') return <StaticPosterFallback />

  const glFactory = async (props: any) => {
    try {
      const renderer = new THREE.WebGPURenderer({
        ...props,
        forceWebGL: mode === 'webgl2',
      } as any)
      await renderer.init()
      const backend = (renderer as any).backend?.isWebGPUBackend ? 'webgpu' : 'webgl2'
      console.log(`[renderer] selected: ${backend}`)
      return renderer
    } catch (err) {
      console.warn('[renderer] init failed, switching to poster fallback', err)
      setMode('poster')
      return null
    }
  }

  return (
    <div
      data-canvas-id="world-canvas"
      style={{ position: 'fixed', inset: 0, zIndex: 0, pointerEvents: 'none' }}
    >
      <Canvas gl={glFactory as any} fallback={<StaticPosterFallback />}>
        <WorldScene />
      </Canvas>
    </div>
  )
}
```
