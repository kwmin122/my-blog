## Objective

Replace every floating UI panel in the world with liquid glass — a `backdrop-filter: blur(12px) saturate(1.8)` surface whose opacity breathes with scroll progress. This plan creates the reusable `UIGlassPanel` component, the `useScrollOpacity` hook that drives the `--panel-opacity` CSS variable via GSAP ScrollTrigger, adds the `.glass-panel` CSS rule to globals, wraps the existing post overlay in `WorldScene` with `UIGlassPanel`, activates the scroll hook in the world page, and adds a `UIOverlay` fixed-position wrapper to `app/layout.tsx` that establishes a proper stacking context for all DOM panels above the canvas.

## Capabilities

VIS-02 — Liquid glass backdrop-filter on all floating UI panels; scroll-driven `--panel-opacity` dynamic range 0.4–0.85

## Delivery scope

- `app/globals.css`: add `--panel-opacity: 0.6` to `:root` block; add `.glass-panel` class rule with `backdrop-filter` and `-webkit-backdrop-filter`.
- `lib/useScrollOpacity.ts`: a React hook that uses `gsap.ScrollTrigger.create` with `onUpdate` to set `document.documentElement.style.setProperty('--panel-opacity', value)` where `value` interpolates from `0.4` (scroll top) to `0.85` (scroll bottom). Uses `gsap.quickSetter` for performance. Cleans up via `ScrollTrigger.kill()` on unmount.
- `components/ui/UIGlassPanel.tsx`: a thin wrapper component that applies `className="glass-panel"` and accepts `className`, `style`, and `children` props. Exports a named `UIOverlay` constant (a `div` with `position: fixed; inset: 0; pointer-events: none; z-index: 10`) for layout use.
- `app/layout.tsx`: import `UIOverlay` from `UIGlassPanel` and wrap the `<main>` tag inside a `<UIOverlay>` so that all page children render in a fixed stacking context above the canvas. The `WorldCanvasLoader` stays outside `UIOverlay` (it is the canvas layer).
- `components/world/WorldScene.tsx`: replace the inline `style={{ background: 'rgba(0,0,0,0.7)', ... }}` div inside `<Html>` with `<UIGlassPanel>`.
- `app/world/page.tsx`: call `useScrollOpacity()` at the top of the component body.

## Technical direction

The `useScrollOpacity` hook must import from the GSAP integration already established in `lib/gsap.ts` — read that file first to understand how `gsap` and `ScrollTrigger` are registered. The hook creates a `ScrollTrigger` with `trigger: document.body`, `start: 'top top'`, `end: 'bottom bottom'`, and `onUpdate: (self) => setter(0.4 + 0.45 * self.progress)`. The `setter` is `gsap.quickSetter(document.documentElement, '--panel-opacity', '')`. The hook must call `ScrollTrigger.refresh()` after creation to account for content that may have already loaded, and must return the `ScrollTrigger` instance for the cleanup `useEffect` to call `.kill()` on.

`UIGlassPanel.tsx` must be a `'use client'` component. It should accept `{ children, className, style }: { children: React.ReactNode; className?: string; style?: React.CSSProperties }` and render a `<div className={['glass-panel', className].filter(Boolean).join(' ')} style={style}>{children}</div>`. The named `UIOverlay` export is a plain functional component that renders `<div style={{ position: 'fixed', inset: 0, pointerEvents: 'none', zIndex: 10 }}>{children}</div>` — it accepts only `{ children: React.ReactNode }`.

The `.glass-panel` CSS rule in `globals.css` must set background using `var(--color-base)` at `var(--panel-opacity)` via the CSS `oklch(.../ var(--panel-opacity))` syntax. Backdrop-filter must include both `blur(12px)` and `saturate(1.8)`. Add a `border` of `1px solid` using `var(--color-text-primary)` at `0.08` opacity. Add `border-radius: 0.75rem` and `transition: background 0.2s var(--ease-default)`. The `--ease-default` custom property is already defined in `globals.css @theme`.

`app/layout.tsx` currently has `<WorldCanvasLoader />` then `<SmoothScrollProviderWrapper><main>`. The new structure should be `<WorldCanvasLoader />` (unchanged, canvas layer) then `<UIOverlay><SmoothScrollProviderWrapper><main id="page-content">{children}</main></SmoothScrollProviderWrapper></UIOverlay>`. This keeps the scroll provider inside the overlay stacking context.
